# Twins Mask Arsenal prototype

Optional package: put `mod/` contents in the offline `cod25/kronos/mods/owner_twins_armory` folder, separately from ALLY -FieldUpgrade. Close the game before installing and keep a backup. Never use the retail Steam folder.

The native Arsenal Ammo Mods category receives an extra **Twins Mask — 500 Salvage** card. Standard offers remain. The server permits the purchase only on Rex Infernus and checks the actual Arsenal context, available mask system, wearer and wallet before completing the native grant and debit. The fixed price is 500. This exposes the mask ability; it does not replace the equipped gun's Ammo Mod.

The adapter clones the proven native table/category/item schema and appends a distinct record. It extends the native filtered-index list so the existing grid owns card construction, scrolling, focus and input. Notification value zero is the server payload; native positional/filter indices identify the card. Standard items, costs, progression and unrelated menus are preserved. The stock purchase helper sends the custom event with two arguments. There is no separately positioned button or manual focus graph.

Native GSC/HKS compilation, production-import auditing and 36 native-contract checks pass. Actual focus, purchase, insufficient-funds rejection, single debit, worn mask and lightning still require an offline Rex Infernus test. Purchases are Rex-only; the Z-Rex's broader map target is separate. To disable, turn this package off in Kronos Library and restart. An equipped native mask can persist in a save and may need normal in-game removal.

Diagnostics use the verified `k1 owner twins:` file logger. Separate local GSC receipts record boot, listener registration, request receipt and results under `kronos/owner_twins_runtime`. These show what actually ran; mock checks do not establish native gameplay success.

Run the root menu checks through the existing container workflow. No native game code, extracted Lua payload, compiled binary or third-party mod is bundled.
