# Twins Mask Arsenal prototype

Optional package: put `mod/` contents in the offline `cod25/kronos/mods/owner_twins_armory` folder, separately from the Z-Rex package. Close the game before installing and keep a backup. Never use the retail Steam folder.

On Rex Infernus, the native Arsenal receives a supplemental **Twins Mask — 500 Salvage** button. Normal Ammo Mod offers remain. The server checks the actual Arsenal context, map, available mask system, existing wearer and wallet before completing the native grant and debit. The initial price is fixed at 500. This exposes the mask ability; it does not replace the equipped gun's Ammo Mod.

The controller fix uses the native styled button and action event, extends one observed reciprocal Down/Up route, and preserves the menu's default focus. It reads final graph writes, excludes its own links and isolates nested builders. The purchase request uses the native two-argument event API. If the native navigation graph cannot be observed, bounded diagnostics state that limitation.

Native GSC/HKS compilation and 28 mocked UI checks pass. Actual focus, purchase, insufficient-funds rejection, single debit, worn mask and lightning still require an offline Rex Infernus test. This package is Rex-only; the Z-Rex's broader map target is a separate feature. To disable, turn this package off in Kronos Library and restart. An equipped native mask can persist in a save and may need normal in-game removal.

Run the root menu checks through the existing container workflow. No native game code, extracted Lua payload, compiled binary or third-party mod is bundled.
